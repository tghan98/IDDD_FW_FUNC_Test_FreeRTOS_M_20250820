# 2026-06-29_TRF_Timing_Fix_Stage4_기기별튜닝_측정계획

## 1. 작업 목적

Stage3에서 Eu 형광감쇠 실재를 확인하고 카세트 광학 경로가 형광 검출의 병목임을 확정했다. 같은 측정 방법을 기기 A, 기기 B에 적용했을 때 방향성은 유사하나 절대 ADC 값에 차이가 발생한다.

본 Stage는 동일 펌웨어를 유지한 상태에서 기기별 보정 파라미터를 산출·적용하여, 복수 기기 간 측정값을 정합시키는 것을 목적으로 한다.

## 2. 현재 상태

- 기기 A, 기기 B는 동일 펌웨어와 동일 Type0 회로를 사용한다.
- 농도별 형광 카세트 측정에서 A/B 기기 간 방향성은 유사하나 절대 ADC 값에 차이가 있다(기기 B가 대체로 높다).
- CH1~CH7 중 CH4에서 가장 강한 감도가 나타나는 경향이 있다.
- 농도별 형광 카세트는 분석 성능 검증에는 적합하나, 기기 자체의 광학·아날로그 감도 차이만 분리해서 보기에는 형광 특성이 섞여 있다.

## 3. 튜닝 전략

### 3.1 2단계 접근

| 단계 | 기준물 | 목적 |
|------|--------|------|
| 1차 | 반사광 카세트 | 기기 광학·아날로그 감도 차이 분리, 보정값 산출 |
| 2차 | 농도별 형광 카세트 | 실제 분석 성능 검증 |

반사광 카세트는 형광물질이 없으므로 LED 반사광만 측정된다. LED 광량, 광학 정렬, PD 감도, TIA/ADC gain, MUX 경로 편차 등 기기 자체 요인을 형광 특성과 섞이지 않게 분리할 수 있다.

### 3.2 보정 흐름

```
Raw ADC → Dark offset 보정 → Channel gain 보정 → 농도 환산 → 결과
```

초기 적용 파라미터는 아래 두 가지로 제한한다.

```c
int16_t dark_offset[7];   // CH1~CH7
float   channel_gain[7];  // CH1~CH7
```

## 4. 측정 계획

### 4.1 공통 조건

| 항목 | 설정 |
|------|------|
| 기준물 | 동일 반사광 카세트 1개 |
| LED current | `cur=500` |
| 채널 | CH1~CH7 전체 |
| 펌웨어 | 동일 바이너리 |
| 전원 | 동일 조건 |
| 환경 | 외부광 차폐 |
| 반복 | 기기별 10회, 매회 카세트 재삽입 |

### 4.2 측정 윈도우

| 용도 | 윈도우 | define | 빈도 |
|------|--------|--------|------|
| 반복 측정 (주) | 0~2000µs | `100 × 20µs` | 10회/기기 |
| 전체 파형 확인 | 0~10000µs | `200 × 50µs` | 1회/기기 |

반복 측정은 Stage2 검증이 완료된 20µs 균등 간격을 사용한다. 전체 파형은 현재 설정(50µs)을 그대로 사용한다.

### 4.3 define 전환

기존 10ms 윈도우에서 반복 측정용으로 전환 시:

```c
// 반복 측정용 (100 × 20µs = 0~2000µs)
#define TRF_REAL_SAMPLE_COUNT           100U
#define TRF_REAL_SAMPLE_INTERVAL_US      20U

// 측정 완료 후 원복
#define TRF_REAL_SAMPLE_COUNT           200U
#define TRF_REAL_SAMPLE_INTERVAL_US      50U
```

## 5. 분석 항목

### 5.1 회차별 측정값

| 항목 | 계산 | 목적 |
|------|------|------|
| Dark 평균 | 0~180µs 평균 | 기본 offset |
| LED ON 평균 | 200~1200µs 평균 | 광량/수광 감도 |
| LED ON MAX | 200~1200µs 최대값 | 최대 반사광 응답 |
| ADC@1250µs | OFF +50µs | 잔류 신호 |
| ADC@1500µs | OFF +300µs | dark 복귀 여부 |

### 5.2 핵심 비교값

Stage3에서 확인된 TIA 포화회복 구간(1200~1380µs)을 고려하여, 반사광 카세트의 기기 간 편차는 LED ON 구간의 평균 응답을 기준으로 한다.

```
LED ON 평균 − Dark       → 기기 간 광학 감도 차이
LED ON MAX − Dark        → 최대 응답 차이 (참고)
```

## 6. 보정값 산출

기기 A를 기준으로 기기 B를 보정한다. 모든 계산은 CH1~CH7 개별로 수행한다.

```c
// 1) Dark offset: 각 기기별 dark 평균의 10회 평균
dark_offset[ch] = mean_of_10_runs(dark_avg[ch]);

// 2) Channel gain: (LED ON avg − dark)의 기기 간 비율
//    B 보정 gain = A 평균 / B 평균
channel_gain[ch] = led_minus_dark_A[ch] / led_minus_dark_B[ch];
```

적용:

```c
corrected = (raw_adc − dark_offset[ch]) × channel_gain[ch];
```

## 7. 검증 (2차: 농도별 형광 카세트)

반사광 카세트로 산출한 보정값을 실제 형광 카세트에 적용하여 확인한다.

- [ ] A/B 기기 간 CH별 편차 감소 (목표: ±5% 이내)
- [ ] CH별 반복 측정 CV(%)
- [ ] 농도별 방향성 유지 여부
- [ ] 특정 채널 과보정 여부 (gain이 0.7 미만 또는 1.3 초과 시 HW 검토)
- [ ] ADC@1350µs 잔류 신호의 기기 간 차이

## 8. 진행 순서

1. 펌웨어 100/20µs(0~2000µs)로 전환
2. 기기 A 반사광 카세트 10회 측정
3. 기기 B 반사광 카세트 10회 측정
4. CH1~CH7별 `dark_offset`, `channel_gain` 산출
5. 보정 테이블 펌웨어에 반영
6. 농도별 형광 카세트로 보정 전/후 비교 검증
7. 측정 완료 후 define 200/50µs로 원복
8. 필요 시 slope/intercept, LED DAC 조정으로 확장 검토

## 9. 잔여 이슈

- 반사광 카세트만으로는 형광 신호의 거동을 완전히 대표할 수 없으므로, 1차 보정 후 반드시 농도별 형광 카세트로 검증한다.
- CH4 최고 감도 경향이 기기 B에서도 동일하게 나타나는지 확인한다.
- 추후 기기가 3대 이상으로 늘어나면 golden device 기준과 보정 테이블 관리 방안을 별도 정리한다.
