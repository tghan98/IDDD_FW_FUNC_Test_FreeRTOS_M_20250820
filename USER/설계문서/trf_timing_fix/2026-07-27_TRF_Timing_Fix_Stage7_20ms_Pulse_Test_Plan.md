# 2026-07-27_TRF_Timing_Fix_Stage7_20ms_Pulse_Test_Plan

## 1. 실험명
TRF Timing Fix Stage7 20ms Pulse Test Plan  
F1 TRF 20ms 관찰창 기반 단발 펄스 실험 계획

## 2. 실험 배경
기존 2ms 측정윈도우 실험을 통해 LED ON 구간은 포화 또는 평탄화 경향이 확인되었고, LED OFF 이후 tail 거동이 LED 점등시간에 따라 달라지는 경향이 확인되었다.  
다음 단계에서는 tail 복귀 시점과 필요한 관찰창 길이를 더 길게 관찰할 필요가 있다.

이번 Stage7은 우선 데이터시트 시간 구조를 참고하여 20ms 관찰창을 구현하고, 단발 측정 기반으로 tail 특성을 확보하는 것을 목표로 한다.  
현재는 암흑 차분이 없는 상태에서 적분값이 회로 방전 성분을 포함할 수 있으므로, Stage7에서는 적분 구간 자체를 확정하기보다 tail이 수렴하기까지 필요한 관찰시간을 확인하는 데 초점을 둔다.  
향후 DMA + Dark 차분 + 적분 구현은 Stage8로 진행한다.

## 3. 이전 2ms 실험 결과
- LED ON 평균값은 전류 및 점등시간 변화에도 약 3670~3674로 큰 차이가 없었다.
- LED 점등시간이 길수록 LED OFF 이후 tail 값이 높아졌다.
- 500μs 점등 < 1000μs 점등 < 1300μs 점등 순으로 tail 증가 경향이 관찰되었다.
- 70mA 조건에서도 LED ON 평균값은 크게 증가하지 않았다.
- LED ON 구간은 포화 또는 평탄화 상태로 의심된다.
- 다음 단계는 LED OFF 이후 tail 관찰 구간 확대가 필요하다.

## 4. 실험 목적
- 1차: 필요 관찰창 확정
- 2차: 점등시간 변화에 따른 ADC tail 변화 확인
- 3차: 전류 증가에 따른 ADC 변화 확인

## 5. LED 데이터시트 조건
대상 LED: VLMU1610-365-135

절대최대정격(발췌):
- DC forward current: 60mA
- Pulse forward current: 300mA
- 300mA 시험 조건: tp=2ms, tp/T=0.1, T=20ms

해석:
- 2000μs ON, 20000μs 반복, Duty 10%는 데이터시트 시험 조건이다.
- 300mA / 2000μs / Duty 10%는 2000μs 펄스 조건의 절대최대값이다.
- 3000μs 이상 점등시간에 대해 이 조건을 그대로 확대 적용하지 않는다.
- 300mA는 권장 동작값이 아니라 절대최대값이다.
- 본 실험에서 300mA를 기본 시험값으로 사용하지 않는다.

주의사항:
- 10ms 브랜치의 IDDD_RunCmd_TRF_Real 함수 설명 주석에는 2ms, 100 samples, 20us 표현이 남아 있어 실제 상수와 불일치한다.
- 이번 단계에서는 코드 수정 없이 문서 주의사항으로만 관리한다.

구조 해석:
- 현재 IDDD_RunCmd_TRF_Real은 20ms마다 자동 반복하는 주기 제어가 아니라, 1회 관찰창 측정 후 로그 출력하고 종료하는 단발 구조이다.
- 따라서 이번 Stage7의 기본 표현은 20000μs 관찰창 내부 2000μs ON 단발 펄스 실험으로 정의한다.

## 8. 20ms 측정윈도우 구현안
기본안:
- 샘플 간격: 50us
- 샘플 수: 400개
- 측정 구간: 0~19950us, 즉 [0, 20000us) 구간
- LED ON 시작 시점: 200us
- LED OFF 시작 시점: 200us + 점등시간(가변)
- 관찰창 길이: 20000us

타임라인 구분:
- t < 200us: Dark
- 200us <= t < 200us + 점등시간: LED ON
- 200us + 점등시간 <= t < 20000us: LED OFF tail 관찰

중요 구분:
- 관찰창 길이는 20000us로 고정되므로, 점등시간이 길수록 OFF 이후 관찰 구간이 줄어든다.
- 측정창 내부 OFF 관찰시간은 19800μs - 점등시간(단, 200μs Dark 구간을 제외한 값)으로 계산되며, 점등시간이 길수록 OFF 관찰 구간이 줄어든다.
- 기존의 17.8ms, 18ms 표기는 2ms 점등 조건에만 해당하는 예시값이며, 가변 점등시간 실험에서는 위 식으로 해석한다.
- 다음 LED ON이 정확히 20200μs에 시작되는 20000μs 반복 주기 제어가 추가되면, 펄스 간 실제 OFF 시간은 20000μs - 점등시간이 된다.
- 즉, 관찰창 내부 OFF 구간과 반복 주기 기준 OFF 구간은 서로 다르며 문서/결과에서 구분해야 한다.

샘플 수 선택 정책:
- 기본: 400개, 0~19950us
- 선택: 401개, 20000us 경계를 포함해야 할 때만 사용
- 이유: 20000us는 다음 주기 시작 경계가 될 수 있으므로 기본 실험은 경계 미포함으로 단순화하고, 경계 검증 시에만 401개를 사용한다.

주기 제어 확인 필요:
- 데이터시트 Duty 10%를 실구동으로 만족하려면 LED 상승 시점이 정확히 20ms마다 반복되어야 한다.
- 현재 함수는 단발 측정 구조이므로 이 부분은 별도 구현/검증 항목으로 관리한다.

## 10. 단계별 실험 절차
1. Phase 1: 전류 50mA를 기본 조건으로 사용하고, 점등시간을 1000μs, 2000μs, 3000μs, 4000μs, 5000μs까지 우선 확인한다. 카세트 3종(0.2/0.3/0.4mm)도 함께 확인하며, 각 조건에서 최소 10회 반복 측정한다.
2. Phase 2: Phase 1 결과를 바탕으로 점등시간을 하나로 고정하고, 전류를 50mA부터 실제 전류와 회로 상태를 확인한 뒤 단계적으로 증가시키며 ADC tail 변화를 확인한다. 60mA는 일반적인 기본 조건이 아니라 최종 상한 후보로 다룬다.
3. Phase 3: Phase 1과 Phase 2 결과를 보고, 두 변수(점등시간, 전류)를 동시에 변화시키는 조합을 결정한다. 이때 점등시간 상한은 사전 확정 없이 경향을 보면서 결정한다.
4. 각 Phase에서 회로 포화, ADC 포화, 발열, 이상 파형이 보이면 즉시 중단하고 이전 단계로 복귀한다.
5. 60mA 초과 조건은 담당자 확인 후 별도 진행한다.
6. 300mA는 회로 가능성 검증 및 담당자 승인 후 별도 실험으로 분리한다.
7. 필요 시 401샘플 모드로 20000us 경계 포함 측정을 추가 수행한다.
8. 주기 반복 제어 필요성이 확인되면 Stage8 사전 과제로 분리한다.

## 12. 결과 판정 기준
필수 판정:
- 타이밍 구조가 의도대로 기록되었는가
- Dark/ON/OFF 구간 분리가 명확한가
- tail이 수렴하는 시점이 재현성 있게 도출되는가
- 반복 측정 편차가 허용 범위 내인가
- ADC 포화 또는 회로 포화 징후가 없는가

수렴 시점 판정 기준:
- 10회 측정을 먼저 평균하여 대표 파형을 만든다
- 바닥값 = 관찰창 꼬리 끝 10% 구간의 평균
- 바닥값 대비 위쪽으로 +2카운트 이내인 샘플이 연속 10개 나오는 최초 지점을 수렴 시점으로 정의한다
- 아래로 벗어난 값은 노이즈로 보고 이탈로 취급하지 않는다 (단측 판정)
- 근거: 노이즈 σ 약 0.73카운트. 허용범위 +1은 정착 후에도 200샘플 중 14회 초과하여 불안정하고, +2부터는 초과 0회로 안정

비교 판정:
- 전류 상승 시 tail/수렴 시점 변화가 유의미한가
- 설정 전류와 실제 전류 차이가 허용 가능한가
- 400개와 401개 결과 차이가 의사결정에 영향을 주는가

관찰 사항:
- LED OFF 후 tail은 Dark 수준(약 127)이 아니라 그보다 약 12카운트 높은 값(약 139)에서 수렴한다.
- 20ms 관찰창 내에서 Dark로 복귀하지 않으며, 후반 하강 속도로 추정 시 약 150ms가 소요된다.
- 따라서 Stage7에서는 암흑 차분이 없는 상태에서 적분값 기반 판정은 제외하고, 수렴 시점과 필요 관찰창 길이를 중심으로 판단한다.

- 시간축: us
- 기본 표시: 원시 ADC 파형, Dark 평균선, ON 구간, OFF 관찰구간
- 비교 그래프:
  - 전류 조건별 tail 겹침 비교
  - 반복 측정 평균 파형과 편차 밴드
- 주석 항목:
  - ON 시작/종료 실측 시각
  - 수렴 추정 시점
  - 잔류 오프셋 기준선(약 12카운트)
  - 포화 구간 표시
- 400샘플 기본 그래프를 기준으로 하고, 401샘플은 경계 검증 부록 그래프로 분리한다.

## 16. 실험 완료 후 다음 단계
- 수렴 시점과 필요한 관찰창 길이를 Stage8 입력값으로 확정한다.
- 전류-응답 민감도 기반으로 추천 전류 범위를 도출한다.
- Stage8에서 DMA + Dark 차분 + 적분 구현을 진행한다.
- Stage8에서 암흑 차분 기반 적분 구간 검증을 추가로 수행한다.
- 필요 시 20ms 반복 주기 제어(실제 Duty 10% 만족) 구현 과제를 Stage8 세부 항목으로 분리한다.
- 고전류 시험은 회로 가능성 검토서와 안전 승인 절차 이후 별도 계획으로 진행한다.

## 17. 미확인 사항 및 담당자 확인 필요 항목
- LED 상승 시점을 정확히 20ms마다 반복시키는 주기 제어 구현 여부
- 4.5V 레일에서 목표 전류 상한의 실제 도달 가능성
- 센스저항 기반 실제 전류 측정 방법과 캘리브레이션 절차
- ADC 클럭/정격 여유에 대한 최종 확인
- LED OFF 후 잔류 오프셋(약 12카운트)의 원인 — 회로 장시간 정착 / 장수명 형광 / 드라이버 잔류전류 중 어느 것인지 미확인. Stage8 암흑 차분 시 공통성분으로 상쇄되는지 확인 필요
- 300mA 시험 진행 승인 조건(회로, 안전, 책임자)
