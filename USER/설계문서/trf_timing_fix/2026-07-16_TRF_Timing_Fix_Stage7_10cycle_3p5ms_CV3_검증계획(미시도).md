# 2026-07-16_TRF_Timing_Fix_Stage7_10cycle_3p5ms_CV3_검증계획

## 1. 작업 목적

본 계획의 목적은 지시에 따라 1사이클 주기 3.5ms 조건에서 ON1~ON10 구간의 형광감쇠 데이터를 수집하고, 동일 조건 반복 측정 데이터의 변동계수(CV)가 3% 이내인지 정량 검증하는 것이다.

기존 Stage5/Stage6가 2-cycle 재연성 및 분리측정 원인 판별 중심이었다면, Stage7은 다중 사이클 반복 환경에서의 수치 안정성을 직접 합격/불합격 기준(CV <= 3%)으로 확인하는 단계이다.

## 2. 수행내용

### 2.1 지시 요구사항 정리

지시의 핵심 요구사항은 다음 두 가지이다.

첫째, 1사이클 주기를 3.5ms로 두고 ON1~ON10 각각의 형광감쇠곡선에서 유의미한 ADC 값 10개를 채집한다.

둘째, ON1~ON10 측정을 10회 반복한 뒤 취합 데이터의 CV가 3% 이내인지 확인한다.

이를 데이터 관점으로 환산하면 1회 수행(run)에서 10사이클 x 10포인트를 확보하고, 동일 수행을 10회 반복해 통계값을 산출하는 구조가 된다.

### 2.2 측정 구조 설계

측정은 TIM3 CNT 기반 폴링 구조를 유지하되, 1사이클 단위를 3500us로 설정하고 총 10사이클을 연속 수행한다.

사이클 내부 LED ON/OFF 절대시각은 기존 정책(ON=200us, OFF=1200us)을 유지한다. 따라서 각 사이클은 ON/OFF 이후 감쇠 관찰 구간을 포함하고, 다음 사이클 시작 전까지 잔여 구간을 동일 주기 내에서 유지한다.

샘플링 간격은 기존과 동일하게 50us를 유지한다. 이에 따라 사이클당 샘플 수는 70개(3500/50), 10사이클 총 샘플 수는 700개가 된다.

### 2.3 유의미 ADC 10포인트 및 CV 산출 정책

본 계획 초안에서는 유의미한 ADC 10포인트를 각 사이클 내 고정 상대시각 포인트로 정의한다. 포인트 후보는 ON 전/직후, OFF 직후 초기감쇠, 중기감쇠, tail 구간을 균형 있게 포함하도록 구성한다.

CV 산출은 동일 포인트 집합에 대해 반복 측정 결과를 취합해 계산한다. 계산식은 CV(%) = 표준편차/평균 x 100이며, 합격 기준은 CV <= 3%이다.

최종 보고는 포인트별 CV, 사이클별 CV, 전체 요약 CV를 함께 제시한다.

### 2.4 예상 코드 변경사항

GUI 명령 수정 없이 기존 `trfrun` 매핑 교체 방식으로 진행한다.

- 변경 대상 함수 파일: `USER/L2_Interface/L2_01_IDDD_RunCMD_Interface/IDDD_RunCmd_TRF_Interface.c`
- 선언 추가 파일: `USER/L2_Interface/L2_01_IDDD_RunCMD_Interface/IDDD_RunCmd_TRF.h`
- 명령 매핑 파일: `USER/L3_Application/L3_01_IDDD_RunCommand_app/IDDD_RunCommand_App.c` (`cmdIDDD_TRF_RUN`)

신규 10-cycle 측정 함수를 추가하고, 기존 Stage5/Stage6 함수 호출은 원복용 주석으로 보존한다. 로그 헤더에는 `10CYCLE_3P5MS` 등 식별 태그를 넣어 기존 SWEEP/GAP 로그와 혼동을 방지한다.

### 2.5 데이터/자원 관점 체크 포인트

샘플 700개 저장을 위한 버퍼 메모리 사용량을 사전 점검한다. 현재 샘플 구조체 기준 약 2.8KB 수준이며, 타 경로 버퍼와 동시 사용 시 여유 RAM 확인이 필요하다.

또한 3.5ms 사이클 경계에서 이벤트 시각(ON/OFF) 및 샘플 타임스탬프가 누락 없이 기록되는지 우선 검증한다.
