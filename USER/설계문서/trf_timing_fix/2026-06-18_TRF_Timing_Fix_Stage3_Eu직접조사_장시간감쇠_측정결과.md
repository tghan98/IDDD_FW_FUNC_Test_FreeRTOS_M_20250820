## 4. 측정 윈도우 확장 경위 및 방법

### 4.1 기존 2ms 윈도우의 한계

Stage2 기본 설정은 `SAMPLE_COUNT=100, INTERVAL=20us`로 측정 범위가 **0~1980us**이다.

```c
// 기존 (Stage2 기본)
#define TRF_REAL_SAMPLE_COUNT           100U
#define TRF_REAL_SAMPLE_INTERVAL_US      20U
```

이 윈도우에서는 Eu 직접 조사 조건의 감쇠가 1980us에서도 dark(135)보다 훨씬 높아(약 1400~1500), 감쇠 종료 시점을 전혀 확인할 수 없었다.

### 4.2 2ms → 4ms 확장

감쇠 종료를 확인하기 위해 1차로 측정 윈도우를 4ms로 확장하였다.

```c
// 1차 확장: 100 → 200 samples, interval 20us 유지
#define TRF_REAL_SAMPLE_COUNT           200U
#define TRF_REAL_SAMPLE_INTERVAL_US      20U
// 측정 범위: 0us ~ 3980us
```

변경 근거: SAMPLE_COUNT만 100→200으로 늘리고 interval은 20us를 유지하여 기존 해상도를 보존하면서 측정 시간을 2배로 확장. 구조체 버퍼 100→200개(400→800바이트)로 SRAM 여유 충분.

4ms 결과: 감쇠는 명확히 관찰되었으나 3980us에서도 raw≈633으로 dark(135)보다 약 500 count 높았다. **4ms로도 감쇠 종료를 확인할 수 없었다.**

### 4.3 4ms → 10ms 재확장

4ms에서도 감쇠가 끝나지 않았으므로, 2차로 10ms까지 확장하였다.

```c
// 2차 확장: interval 20us → 50us, count 200 유지
#define TRF_REAL_SAMPLE_COUNT           200U
#define TRF_REAL_SAMPLE_INTERVAL_US      50U
// 측정 범위: 0us ~ 9950us
```

변경 근거: SAMPLE_COUNT를 200으로 유지하여 UART 출력량과 버퍼 크기를 보존하고, interval만 20→50us로 늘려 측정 시간을 2.5배 확장. 감쇠 후반부는 변화가 완만하므로 50us 해상도로도 충분하다.

주의: interval 변경 시 기존 `TRF_REAL_DARK_COUNT = 10` 고정 방식으로는 dark 구간이 0~450us까지 확장되어 LED ON 샘플이 dark 평균에 섞인다. `tim_us < TRF_REAL_LED_ON_US` 조건으로 보정하여 실제 dark(≈135)를 산출하였다.

### 4.4 4ms/10ms 교차 검증

Eu 직접 조사 조건에서 4ms 측정(20us 간격)과 10ms 측정(50us 간격)의 동일 시점 값을 비교하였다.

| 시점 | 4ms 측정 | 10ms 측정 | 차이 |
|---:|---:|---:|---:|
| 1500us | 2506 | 2563 | +2.3% |
| 2000us | 1435 | 1422 | -0.9% |
| 3000us | 940 | 929 | -1.2% |

측정 간격이 달라도 동일 시점 ADC raw 값이 ±3% 이내로 일치하여, 폴링 기반 측정의 재현성과 interval 변경에 대한 신뢰성을 확인하였다.

## 5. 결론

1. **Eu 형광감쇠는 실재한다.** 빈 상태 대조군에서 10ms 전 구간 신호가 완전히 소멸하므로, Eu 직접 조사에서 관찰된 장시간 tail은 유로피움 형광 발광이 확실하다.

2. **1.0mm 카세트에서도 미약한 형광감쇠가 검출된다.** 약 2500us에서 작은 peak가 나타난 뒤 dark로 수렴하므로, 카세트 경로에서 형광이 완전히 소실되는 것은 아니다. 다만 직접 조사보다 신호가 크게 약하므로 여기광-발광 경로의 광학 정렬과 전달 효율 개선이 필요하다.

3. **감쇠는 약 9ms에 완료된다.** 1500us peak → 9ms plateau, 전체 감쇠 구간 약 7500us. 다중 지수감쇠 특성을 보이며 초반 τ ≈ 1~2ms, 후반 τ ≈ 3~4ms로 점차 느려진다. 10ms 시점에서 dark+10으로 종료된다.

파형의 전체 흐름:

```text
LED ON 종료 (1200us)
→ 1200~1350us: TIA 포화회복 (dark 근처)
→ 1400us: 형광 상승 시작
→ 1500us: peak
→ 1500us~9ms: 단조감쇠 (다중 지수)
→ 9~10ms: dark+10 plateau 도달
```

## 6. 주의사항 및 후속 조치

### 6.1 dark 계산 보정 완료

2026-06-18에 코드의 dark 계산 방식을 보정했다. 기존 코드는 `TRF_REAL_DARK_COUNT = 10`을 고정 사용했다. 20us 간격에서는 0~180us가 dark 구간이라 문제가 없지만, 50us 간격에서는 0~450us가 평균에 포함되어 LED ON 이후 샘플이 섞였다.

수정 후에는 sample count가 아니라 타임스탬프를 기준으로 LED ON 이전 샘플만 dark 평균에 포함한다.

```text
tim_us < TRF_REAL_LED_ON_US 인 샘플만 dark 평균에 포함
```

이 방식으로 바꾸면 20us, 50us 등 interval 변경과 무관하게 dark 평균을 안정적으로 계산할 수 있다.
